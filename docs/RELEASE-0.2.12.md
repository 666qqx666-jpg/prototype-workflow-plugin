# 原型工作流插件 0.2.12 · 预发布

本次更新汇总0.2.2公开首发之后的定向修复。公司服务配置继续外置，旧需求继续使用其绑定执行器。

## 累计变化

- 原页面继承更明确。区分需求事实、页面基线及现役原型，保留原入口、组件层级、布局关系和关键控件尺寸；原有查询、保存、重置等行为不自动写成新增变化卡。累计阅读稿继续保留已有身份与确认内容。
- 阅读返回恢复业务草稿。支持可序列化的业务状态适配，并修复已选上传文件返回时被浏览器拒绝回填路径的问题。动态模型、选择状态及原生文件选择分别恢复。
- 导入导出使用真实工作簿。增加本地SheetJS资产、单文件嵌入工具和行处理汇总辅助函数。实际下载模板、上传混合数据、导出失败原行、修正后重导；项目表头、主数据和具体业务规则仍来自当前任务。
- 安装与诊断更稳定。修正原生缓存替换导致工作目录失效、导入校验包产生字节码漂移等问题；失败只暴露白名单诊断码。维护者可通过独立私有候选入口在隔离目录验证，不改变普通公开来源刷新。

## 已验证与限制

- 本机macOS、Python 3.12、Node.js 22；使用锁定本机依赖缓存，安装Core/Chromium检查133/133通过，20个跨Agent入口链接核对通过。
- 限定导入业务页及同页阅读稿的实际XLSX往返通过。五行混合输入得到2成功/3失败，失败数据修正后为3成功/0失败；未知关联错误行不阻断后续独立正确行。
- 阅读稿选择文件后连续两次定位与返回，仍能提交同一文件；说明卡双向定位、连线及返回审计通过。
- 业务页独立生成后无需维护者手工修改业务代码，阅读说明接受过一次来源纠偏。该结果不证明任意需求均能无纠偏完成。
- 真实后端权限、跨系统业务接续、多人并发、同事实际环境及无缓存冷安装不属于上述结论。正式业务交付仍需真实独立Review与最终Gate。

## 更新方式

保持原marketplace与插件标识。全新需求检查维护者批准发行；入口版本未重载时按`reload_required`提示处理。继续旧需求使用其原输出目录，仍绑定旧版本，不自动迁移已有Run。网络失败的回退继续显示实际使用版本。

本版为预发布。旧0.2.2归档与Release保留，项目整体许可证维持未选定状态；SheetJS与PyYAML第三方许可随相关资产保留。
