# 0.2.2 本地候选修订

0.2.0 在切换默认入口后写入当前版本记录失败，会留下记录与入口不一致。0.2.2 将入口激活、安装复验和当前版本发布置于同一失败恢复范围。0.2.1 仅用于历史合成更新测试，本修订不以它作为批准候选。

发布前保存旧记录的原始字节与权限，并在原子替换前记录暂存文件身份。捕获到异常或中断后，安装器按已有 Receipt 恢复本次入口；指针仅在仍属于本事务时恢复旧字节，首次安装则移除本次指针。已有安装不会因一次记录写入失败而被回滚。未知目标会被保留并报告 `INSTALL_RECOVERY_FAILED`，需要排查；不写入新需求绑定、不报 ready。文件系统超时不属于网络 fallback。

本次仅改外层管理器与存储协作者，kit 安装器、业务门禁、查询、Reader、核心 Skill 和 Pack 内容保持不变，版本身份由构建器机械更新。版本目录、历史 Receipt、旧需求绑定及成果保留；回滚后的新安装状态为 `rolled_back`，不作为成功激活。

覆盖可捕获失败与 KeyboardInterrupt；未证明断电、SIGKILL 或文件系统持续不可写后可自动恢复。恢复本身失败时明确阻断。原 0.2.0 实体及证据保留，本修订重新构建并绑定实际分发入口，等待定向独立复验。

所有验证使用隔离 HOME。真实安装器保留其依赖、Chromium 和内建 Smoke；仅身份及 SSH 传输合成，没有业务独立验收、正式 GitHub 来源安装或实际桌面安装。未上传、未公开、未选择项目许可证。
