# 原型工作流初始化
入口发行：0.2.0。
1. 从本 SKILL.md 所在目录向上两级定位插件根，在该目录调用 Python 模块 plugin_runtime.cli；不扫描 HOME 找其他版本。
2. 复用已知材料，一次集中确认缺少的可信 company-profile 路径、已有 SSH 用户名和密钥文件路径；不索要私钥正文，不申请账号或公共 Probe。
3. 调用 setup，传入当前插件根和已确认的三个输入。只使用模块返回的配置、环境、认证、list 与安装状态；不根据文案或模拟测试宣称已初始化。
4. 缺少依赖时给出实际缺项和补齐操作，不自动改变系统环境；身份、主机与服务失败按稳定错误码说明，不笼统要求联系管理员。
5. 仅在 ready 时提示可以开始新需求；其他状态保留脱敏记录，不生成成功结论，不上传反馈。
